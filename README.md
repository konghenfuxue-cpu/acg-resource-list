# ACG 资源目录

一个以卡片展示资源条目的静态网页目录，支持关键词搜索、分类筛选、时间标签和隐藏偏好。适合集中浏览、查找与分享目录中已有的资源入口。

**下载本仓库后，在浏览器中打开 [index.html](index.html) 即可查看。** 页面样式、数据和交互集中在这个 HTML 文件中，无需安装 Node.js、执行构建或配置数据库。

## 可以做什么

- 按作品、分类或网盘关键词搜索，支持简繁体搜索。
- 按分类和时间标签筛选，按最新更新或名称排序。
- 隐藏不想显示的分类或标签，并恢复全部内容。
- 从卡片打开资源详情弹窗，查看链接与说明。
- 使用页面提供的反馈和分享入口。
- 在手机与桌面浏览器中使用自适应布局。

隐藏偏好保存在当前浏览器的本地存储中，不会自动跨设备同步。浏览器限制存储或清理站点数据可能影响偏好保留。

## 使用与维护

### 浏览目录

1. 在仓库页面选择 **Code → Download ZIP** 并解压。
2. 用现代浏览器打开 `index.html`。
3. 使用搜索框和筛选项定位条目，点击“查看资源”打开详情。

资源链接会跳转到第三方站点；目录页面本身不是文件存储或下载服务，链接可用性与访问条件由对应站点决定。

### 修改自己的目录

使用文本编辑器打开 `index.html`，参考现有条目修改资源数据。页面 CSS 与 JavaScript 也在同一文件中，适合小规模维护；修改后刷新浏览器，核对搜索、筛选、详情弹窗与链接。

公开发布前，也请检查页面中的群组、反馈、分享地址及二维码是否仍指向你希望使用的目标。

### 部署为静态页面

将 `index.html` 放到支持静态 HTML 的托管服务即可；无需后端。仓库当前仅包含页面文件，没有单独的构建流程或自动测试套件。
